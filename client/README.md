# @cocono/client

Event-driven JavaScript SDK for the cocono-chat API — the single place all
client logic lives (registration, login, device pairing, E2EE messaging).
Runs isomorphically in browsers and Node.js ≥ 22.9.

**Full documentation: [/docs/CLIENT_SDK.md](../docs/CLIENT_SDK.md)**

```bash
pnpm --filter @cocono/client test   # unit + integration (boots the real BE)
```
